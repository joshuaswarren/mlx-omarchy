## What ships (two bugs)

1. **Bare `--submit` regression**: with no URL argument, the submission
   pipeline did not stage a temp archive before upload (the public
   endpoint expects a file handle). The fix writes a temp archive in
   the workspace and points the upload at it; the default URL
   (`MLX_OMARCHY_SUBMIT_URL`, set to
   `https://mlx-omarchy-community-data.joshua-s-warren.workers.dev`) is
   the public community endpoint and is unchanged.
2. **Serial-family dtc properties**: the redaction step stripped the
   common devicetree node names but missed the `serial-*` family of
   properties (`serial-number`, `device-serial`, etc.) on qualified
   hardware. They are now redacted out of the archive alongside the
   rest of the privacy scan, before upload.

A separate server-side PII change (strip instead of reject) deploys
independently and also helps v0.7.22 collectors.

## Exact tester command (from a checkout of this tag)

```bash
python3 scripts/collect_deep.py --ane-smoke --submit
```

Runs the pre-flight probe + the redacted upload; the public endpoint
answers with a community-data receipt.

touches only the collector, not the engine.
