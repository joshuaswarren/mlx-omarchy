## What shipped

Three changes since v0.7.13, all on `07729f401`:

1. **Collector dump cap fix** (`972751912`, `07729f401`): `collect_deep`
   macOS ANE dump cap was raised so large macOS dumps parse instead of
   failing. v0.7.13 could not publish `ane_macos` for large dumps.
2. **Conv 1-D k-tap GEMM decomposition re-landed** (`8db7abb73`):
   restricted to fp32 rank-1 convs on the Kokoro vocoder path. Numpy-
   reference exact, M2 RTF 1.21 median, zero-CPU. Kokoro is NOT the
   default engine; listening confirmation pending; Kokoro real time is
   NOT claimed as qualified.
3. **Fused SDPA VJP rep=1** (`b4152c19`): training gradients only,
   fd-proven on M2. GQA rep>1 stays on the composed path pending the
   reduce fix.

Known limits (carried from v0.7.13): speech output real-time threshold
still unmet (voice output stays unqualified); automatic routing stays
off; Quality (27B) misses the 2.0 s first-text budget through the
assistant API; pair-level qualification untested; composed-gradient
caveat outside this release's scope.
