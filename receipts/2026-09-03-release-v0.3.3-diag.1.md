# 2026-09-03 — Release v0.3.3-diag.1, dev diagnostics prerelease (GPU profiling in)

Prerelease, not a full release. GitHub must not advertise it as Latest; `gh release view`
confirms `prerelease: true`, `draft: false`. Tag `v0.3.3-diag.1` cut from main at
`e82f6fb78b777be03e6e868683f80b4004157d7b` with `gh release create v0.3.3-diag.1 --repo
joshuaswarren/mlx-omarchy --target e82f6fb... --prerelease`. Release URL:
https://github.com/joshuaswarren/mlx-omarchy/releases/tag/v0.3.3-diag.1

Purpose: give community contributors on Apple Silicon Linux a wheel with the GPU
profiling harness compiled IN, so they can send profiles back without a source build.
Release wheels keep `MLX_OMARCHY_GPU_PROFILING` OFF by default; this is the sanctioned
dev channel, stamped `+diag`, documented as slower and not for production in the release
notes and in CONTRIBUTING.md.

## Build

jwm1 (M1, 8 cores online), fresh clone at `$HOME/mlx-omarchy-diagbuild` (build trees and
artifacts under `$HOME`; `/tmp` is wiped on reboot):

```bash
cd ~/mlx-omarchy-diagbuild
./scripts/build-wheel.sh --diagnostics
# [receipt] wheel: dist/mlx_omarchy-0.32.2.dev202609031348+diag-cp314-cp314-linux_aarch64.whl
# [receipt] size: 6803505 bytes
# [receipt] sha256: 1939cd388f8be630a3192c6b88ad1fc0d425b758f811e4bd50d3d3a3eb8094f5
# [receipt] profiling harness: compiled IN (MLX_OMARCHY_GPU_PROFILE literal found in wheel)
# [receipt] staged tool: dist/mlx-omarchy-info
```

`--diagnostics` (new in `scripts/build-wheel.sh`, commit `cdfa84d`) appends
`-DMLX_OMARCHY_GPU_PROFILING=ON` to CMAKE_ARGS, sets `DEV_RELEASE=1` plus
`MLX_OMARCHY_LOCAL_VERSION=diag` (new opt-in env var in `patches/mlx-version-time.patch`),
hard-gates the staging step on the profiling literal being present in the wheel, and
stages `mlx-omarchy-info` from the wheel itself. Default invocation is unchanged: no
flag, same CMake flags, same version stamp (verified by an A/B of `get_version()`:
no-env yields `0.32.2.dev202609031325+c86f617` exactly as before the patch change).
