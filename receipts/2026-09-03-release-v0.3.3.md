## Scope note and known gap

The release carries the dispatcher batching win, the auto-eager
compiled-tape gate on Apple GPUs, and the provenance/traceability work.
The compiled-tape interpreter defect itself is NOT fixed in this tag;
the runtime fences it by default (one warning, eager values identical).
User-facing summary is in the release notes; defects live in
`docs/known-defects.md` at the tag.

Gap, stated plainly: this release carries the x86_64 (cp311) wheel
only. The aarch64 cp314 wheel built on jwm1 in previous releases is not
attached - jwm1 was reserved for the pinned measurement protocol
tonight and was not touched. The measured numbers in the notes come
from an aarch64 build of the same source tree (`56cb642`) on the M1.
v0.3.2's cp314 wheel remains the newest Apple Silicon asset until the
aarch64 build of v0.3.3 is attached to this release.
