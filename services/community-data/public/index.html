mlx-omarchy community data

Community-contributed hardware and benchmark reports for mlx-omarchy. Submissions are redacted by the contributor's own machine before upload, content-addressed by SHA-256, and published only after every chunk is verified. Coding agents read the same data through the endpoints below.

Machine-readable endpoints

  • GET /v1/results — every published summary as one JSON document
  • GET /v1/results/<sha256> — one full record
  • GET /v1/results/<sha256>/archive — the original redacted archive bytes
  • GET /v1/dataset/latest.jsonl — one JSON object per line, for bulk agent consumption
